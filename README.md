# על הדרך

אפליקציית ריצה לטלפון: GPS מדויק, ספירת צעדים, מפה, היסטוריה, מסלולים שמורים ותוכנית אימונים.
כתובת: https://amitbusi10-pixel.github.io/run/

`screenshot-1.jpg` מוצג בחלון ההתקנה. כדי לצלם אותו מחדש, פותחים את האפליקציה עם `?shot=1` (ריצה לדוגמה, בלי שמירה).

## איך מתקינים בטלפון (Samsung S23)

כדי ש־GPS יעבוד, האפליקציה צריכה כתובת אינטרנט מאובטחת (https). הדרך החינמית והפשוטה היא GitHub Pages:

1. נכנסים ל־github.com ופותחים חשבון חינמי.
2. יוצרים מאגר חדש (New repository), למשל בשם `run`, ומסמנים Public.
3. בתוך המאגר לוחצים על **Add file ← Upload files** ומעלים את כל הקבצים מהתיקייה הזו:
   `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`.
4. נכנסים ל־**Settings ← Pages**, בוחרים ב־Branch את `main` ולוחצים Save.
5. אחרי דקה־שתיים תופיע כתובת בסגנון `https://שם-המשתמש.github.io/run/`.
6. פותחים את הכתובת ב־Chrome בטלפון, ובתפריט ⋮ בוחרים **הוספה למסך הבית** או **התקנת אפליקציה**.
7. בפתיחה הראשונה מאשרים גישה למיקום.

## חשוב לדעת

- בזמן הריצה המסך צריך להישאר פתוח על האפליקציה. האפליקציה שומרת עליו דולק לבד, אבל אם יוצאים ממנה או נועלים את המסך, ה־GPS מפסיק לעקוב.
- כדי לחסוך בסוללה אפשר להנמיך את בהירות המסך.
- הצעדים נספרים מחיישן התנועה של הטלפון. כדאי להחזיק את הטלפון ביד, בכיס או ברצועה על הזרוע.
- כל הנתונים נשמרים רק בטלפון. כדאי לייצא גיבוי מדי פעם ממסך **הגדרות**.
